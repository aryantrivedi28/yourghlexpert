## 🚀 Quick Start (3 Steps)

### Step 1: Setup (5 min)
```bash
npx create-next-app@latest yourghlexpert --typescript --tailwind --eslint --app
cd yourghlexpert
pnpm add lucide-react next-seo json-ld-script react-hook-form zod axios swr
pnpm dev
```

- Copy color palette from QUICK_START.md
